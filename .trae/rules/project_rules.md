# 项目规则

## 核心工作流规则

### 全栈团队模式（默认激活）

**每次执行开发任务时，必须先调用 `fullstack-team` Skill**，进入 Elite Software Corp 29 人全建制团队模式：

1. **TPM（技术项目经理）自动定级**：L1（快速修复）/ L2（标准流程）/ L3（全建制）
2. **按级别激活对应角色**：L1 出动 6 人，L2 出动 17 人，L3 全员 29 人
3. **严格遵守质量门禁**：CRL 审查 → SEC 安全审计 → QA 两轮全绿 → 才可交付
4. **全自动执行到底**：不在中途询问用户确认，用户只看最终结果

### 具体执行方式

收到用户开发任务后，执行：

```
Skill: fullstack-team  →  TPM 定级  →  按级别流程执行  →  交付报告
```

### 禁止行为

- 禁止跳过 fullstack-team 直接写代码
- 禁止跳过 QA 测试直接交付
- 禁止用语法检查冒充功能测试
